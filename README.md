# CN5006 – Web and Mobile Application Development

## Week 5 Practical: Express.js and MongoDB

This repository contains my weekly practical work for the CN5006 Web and Mobile Application Development module.

### Files

- `index.js` – Express server and REST API routes.
- `week4Practice.js` – MongoDB operations using Mongoose.
- `Personform.html` – Person registration form.
- `StudentInfo.html` – Student information form.
- `Students.json` – Student information dataset.

### Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- HTML
- JavaScript

### Main Learning Outcomes

- Creating routes using Express.js.
- Handling GET, POST, PUT and DELETE requests.
- Connecting an Express application to MongoDB.
- Performing CRUD operations using Mongoose.
- Returning JSON responses from REST API endpoints.
